## Core business

Frappe owns provider access/sync. Credentials stay encrypted on the server; selecting a source does not bypass app permissions.

## Primary workflow

1. Configure and verify the tenant provider connection.
2. Map users and select provider-owned data sources.
3. Preview enquiry/catalog data through fixed provider contracts.
4. Queue imports/synchronisation, inspect progress/failures and retry through the owner workflow.
