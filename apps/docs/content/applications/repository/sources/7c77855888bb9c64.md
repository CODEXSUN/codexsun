## Scoped API token in root .env

Use a dedicated API token for unattended operations.
Create it in Cloudflare with only the required account, zones, permissions, and expiration.
For domain inventory, start with Zone Read on the selected zones.
Add DNS Read only when DNS inspection is required.
Grant DNS Edit or deployment permissions only for an authorized task.
Do not use the Global API Key or the dashboard password.

Merge these keys into the ignored root `.env`. Preserve all existing entries.

```dotenv
CODEXSUN_CLOUDFLARE_ACCOUNT_ID=a68cf61bf5bae3f83ddb7765dc29a835
CODEXSUN_CLOUDFLARE_ZONE_ID=fd99a25e62c1046a678a02e31e78dd29
CODEXSUN_CLOUDFLARE_API_TOKEN=
```

Enter the actual token locally. An empty value is a placeholder, not working authentication.
Never commit real values to `.env.example`, Markdown, Wrangler configuration, or frontend variables.
The account and zone IDs are identifiers. The API token is a secret.

CODEXSUN stores its own keys with the `CODEXSUN_` prefix.
Map them to Cloudflare's required process variables only for CLI execution.
This PowerShell example uses the repository's installed `dotenv` parser:

```powershell
Set-Location D:\workspace\codexsun
$cfSettings = node -e 'const fs=require("fs"); const d=require("dotenv").parse(fs.readFileSync(".env")); console.log(JSON.stringify({account:d.CODEXSUN_CLOUDFLARE_ACCOUNT_ID,token:d.CODEXSUN_CLOUDFLARE_API_TOKEN}));' | ConvertFrom-Json
if (-not $cfSettings.token) { throw 'Set CODEXSUN_CLOUDFLARE_API_TOKEN locally first.' }
if ($cfSettings.account -ne 'a68cf61bf5bae3f83ddb7765dc29a835') { throw 'Unexpected Cloudflare account.' }
$cfPreviousToken = $env:CLOUDFLARE_API_TOKEN
$cfPreviousAccount = $env:CLOUDFLARE_ACCOUNT_ID
try {
    $env:CLOUDFLARE_API_TOKEN = $cfSettings.token
    $env:CLOUDFLARE_ACCOUNT_ID = $cfSettings.account
    wrangler whoami
    if ($LASTEXITCODE -ne 0) { throw 'Cloudflare authentication failed.' }
} finally {
    $env:CLOUDFLARE_API_TOKEN = $cfPreviousToken
    $env:CLOUDFLARE_ACCOUNT_ID = $cfPreviousAccount
    $cfSettings = $null
    $cfPreviousToken = $null
}
```

Do not rely on automatic `.env` loading for this mapping.
An explicit `CLOUDFLARE_API_TOKEN` overrides Wrangler OAuth authentication.
The token path above was documented but not tested with a new API token.

## Choose the correct client

| Operation                                     | Client                                  |
| --------------------------------------------- | --------------------------------------- |
| Workers, Pages, D1, KV, and related resources | Wrangler                                |
| Zones and DNS inventory or changes            | Cloudflare REST API with a scoped token |
| Tunnel connector and Access TCP client        | cloudflared                             |

Read-only CLI checks:

```powershell
wrangler whoami
wrangler d1 list --json
wrangler pages project list
cloudflared --version
```

Use `GET /client/v4/zones?account.id=ACCOUNT_ID` for domain inventory.
Use `GET /client/v4/zones/ZONE_ID/dns_records` for DNS inventory.
Send the API token in the `Authorization: Bearer` header, never in the URL.
Check API success and pagination. Do not print request headers or credentials.
OAuth scopes and API-token permissions can differ. Do not assume DNS Edit access from a successful zone listing.

For the existing database tunnel, follow [the tunnel runbook](../docs/cloudflare.md).
Its documented hostname is `data.codexsun.com`, with local listener `127.0.0.1:13307`.
Those route details were source-checked only during this task.
Keep tunnel credentials separate from API tokens and database passwords.
Do not start a connector, change routes, or deploy resources just to verify authentication.

## Worker secrets

Cloudflare management tokens authenticate the CLI. Worker runtime secrets are separate.
Use `wrangler secret put SECRET_NAME --config PATH` to enter an authorized Worker secret interactively.
Never pass secret values as command arguments.
Do not upload the root application `.env` wholesale as Worker secrets.
Do not place credentials in Wrangler `vars`.
