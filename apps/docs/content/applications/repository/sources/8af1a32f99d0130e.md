# Ordered business import verification

## Implemented flow

Database Connection exposes one action for the verified connection pair.
The server queues Common → Masters → Billing and orders each group by target parent relationships.
Saved verified mappings support different source and target names.
Foreign IDs resolve through destination business identity, including renamed invoice parents and nested descendants.
The worker preserves existing conflicts and deleted history.
New dependent records wait when their required parent needs review.

One saved report has Summary, Common, Masters, Billing, Invoices, and Warnings tabs.
Internal chunk sessions do not create duplicate report entries.
Table rows show extracted source, prepared target, saved target, and foreign ID mapping.
Invoice links filter to the exact invoice and its saved descendant source IDs.
Paginated tables have bounded scroll areas and fixed headers.
