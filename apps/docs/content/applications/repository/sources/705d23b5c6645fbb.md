# Standards reference logos

These marks identify standards in an educational section. They do not certify Tirupur Connect or any listed business.

Sources:

- GOTS: https://global-standards.org/images/logos/gots-logo_rgb_2018_transp.png
- GRS artwork, including Textile Exchange copyright credit: https://www.halcousa.com/wp-content/uploads/GRS_Color_sq.png
- OEKO-TEX STANDARD 100 artwork: https://www.galaxy-uniforme.com/img/cms/OekoTexStandard100_Logo.png

GOTS came from the standards owner. GRS and OEKO-TEX copies came from public third-party presentations and were visually checked against the standard identities. Original PNGs remain here. Delivery files remove outer whitespace and use lossless WebP, preserving colors and proportions.

Official information and usage guidance:

- https://global-standards.org/resources/q-a
- https://textileexchange.org/knowledge-center/documents/standards-logo-use-specifications/
- https://www.oeko-tex.com/en/labelling-guide/
- https://www.iso.org/iso-name-and-logo.html

ISO restricts its official logo. The site therefore uses plain ISO 9001 reference typography, without the official globe or a certification seal. No logo permission or certification approval is claimed. The ISO reference is rendered as HTML, not stored as an official logo asset.
