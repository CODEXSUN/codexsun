# Sys Work

Sys Work is a local Windows cleanup DevKit. It scans known generated files from Codex, Antigravity, WebStorm, Android tooling, and AppData. The frontend and backend run separately during development. The built backend serves the frontend on port `7061` by default. Both servers bind to `127.0.0.1`.

The backend owns the cleanup catalog and deletion rules. The browser cannot submit a path. A scan records eligible files for ten minutes. Clean requests must select catalog IDs from that scan and type `DELETE`. Before unlinking each file, the backend checks that it remains in an approved location, that no ancestor became a link, and that its size and modification time still match the scan. Locked or changed files are skipped. A scan never follows symbolic links or Windows junctions.

The catalog covers generated caches, logs, downloads, `C:\\Windows\\Temp`, and the user's `AppData\\Local\\Temp`. It also inventories larger protected areas such as Codex sessions and history, OpenCode data, WebStorm installed agents, Android SDK and virtual devices, Chrome profiles, and Windows app package data. Inventory rows show sizes and largest files but cannot be selected for deletion; the API rejects them too. Cleanable areas include WebStorm IDE caches, Gradle downloads, npm's npx cache, and Playwright browser downloads. The catalog does not target Antigravity app storage, project history, emulator user disks, Chrome profiles, or project source. File age defaults to seven days. The UI also offers 30 days and all ages. Cleaning removes files but leaves directory structures in place. Windows temp files that need elevated access or are in use are skipped.

## Run

Run npm commands from the repository root. Use two terminals for development:

```text
npm run dev:sys-work:api
npm run dev:sys-work:web
```

Open `http://127.0.0.1:7060`. For a built single-port app, run `npm run build:sys-work` and `npm run start:sys-work`, then open `http://127.0.0.1:7061`. Use `CODEXSUN_SYS_WORK_WEB_PORT` and `CODEXSUN_SYS_WORK_API_PORT` to change the ports.

Run `npm run test:sys-work`, typecheck and lint both workspace packages, and `npm run check:component-docs` before release. The backend supports Windows only. No database or tenant integration is required. The catalog in `api/src/catalog.ts` is the extension point for future cleanup areas.
