# Q Cafe developer guide

Restaurant POS with Platform login for web and separate PIN login for desktop.

<Callout title="Implementation scope">
  Web menu and takeaway POS use Platform tenant identity and MariaDB. Desktop retains PIN login and
  SQLite. Desktop enrollment and synchronization remain deferred.
</Callout>

## Core business

Web requests require live Platform tenant activation and permissions. Desktop PINs and license keys do not grant cloud authority.

## Primary workflow

1. Enable QCafe for the tenant and apply its migrations and permission seeds.
2. Sign in to Platform and open QCafe.
3. Maintain the restaurant menu through the tenant API.
4. Save takeaway bills, collect payments, and print receipts from saved records.
5. Keep desktop PIN/SQLite operations separate. Dine-in, kitchen, tax configuration, and remaining web pages are follow-up work.
