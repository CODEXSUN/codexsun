## Core business

Blog is maintained as an external package. This checkout documents integration boundaries, not private package implementation.

## Primary workflow

1. Enable Blog and provision the external package through its public migration/host contract.
2. Open the composed article/editor workspace.
3. Maintain permitted articles/authors/media and review publishing/SEO/discussion capabilities from the installed package.
