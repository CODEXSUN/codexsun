# Zetro Coding Workers Web Module

- Module ID: `zetro.coding-workers.web`
- Version: `1.0.0`
- Owner: Zetro web

## Purpose

This module owns the Worker Queue rail destination and worker handoff form. The form collects repository path, approved scope, criteria, checks, and explicit review confirmation. It shows the daily coding tool profile, Git isolation boundary, and prepared attempts.

The page uses public `@codexsun/ui` controls. It can run the recorded verification checks and record human approval or rejection. It does not start an autonomous coding worker, create a pull request, or merge.
