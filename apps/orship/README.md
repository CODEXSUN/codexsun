# Orship

Orship is the CODEXSUN orchestration application. It coordinates a reviewed
revision through preview, verification, manual approval, VPS deployment, live
checks, monitoring, and rollback evidence.

Orship owns operational records and provider adapters. It does not own product
source, product business logic, provider credentials, or arbitrary VPS command
execution.

register](../../assist/execution/apps/orship/task.md) before starting a task.
