# UIUX

UIUX is the repository design-system gallery.

It is a UI-only application profile. It composes public `@codexsun/ui` exports and does not own an API or product business module.

Use UIUX to inspect approved components, blocks, pages, templates, variants, states, and accessibility metadata.

Do not import UIUX source from another application. Reusable controls belong in `packages/ui` and applications consume its public exports.
