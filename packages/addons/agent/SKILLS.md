# Business Add-On Agent Skills

This document lists the skills required to implement and review the business add-on ecosystem.

## Required Skills

- Repository analysis and CODEXSUN Assist navigation.
- TypeScript, Node.js, and React.
- Framework provider and module contracts.
- API design, validation, and versioning.
- Database design, migrations, seeders, and backup rules.
- Authentication, authorization, workspace isolation, and audit logging.
- Typed events, idempotency, jobs, queues, webhooks, and retries.
- Email, real-time messaging, calendar, rich text, knowledge, social, Git, and workflow integrations.
- Shared UI composition and accessible workspace design.
- Unit, integration, API, browser, security, and performance testing.
- Docker, CI/CD, observability, documentation, and Git workflows.

## Rules

Inspect the current repository before choosing a technology or creating a shared service. Keep domain logic in the owning add-on. Use public contracts for cross-add-on communication. Add tests with each behavior. Record verified, partial, and untested paths.
