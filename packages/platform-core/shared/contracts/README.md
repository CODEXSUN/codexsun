# Platform Contracts

This package owns stable shared Zod and TypeScript contracts. It must not contain app-specific entities or business workflows.

The contracts cover response metadata, success and error envelopes, liveness, readiness components, structured diagnostics, and complete System runtime module metadata. Platform API converts these Zod output contracts into Fastify response schemas.
