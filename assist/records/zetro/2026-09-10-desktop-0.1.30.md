# Zetro Desktop 0.1.30 build

## Scope and references

Package the existing 0.1.30 source candidate as a Windows MSI.
The canonical helper already aligned workspace, lockfile, Tauri, and Rust versions in the previous experiment.
This build keeps version 0.1.30 and preserves all pending source changes.
No application behavior, database schema, or sandbox policy changes in this packaging step.

- [Desktop owner](../../../../apps/zetro/desktop/README.md) defines runtime assembly and packaging.

## Assembly and binding

`npm.cmd run desktop:zetro:msi` refreshes the web bundle and bundled API through the repository build helper.
Tauri packages that web output, the private Node runtime, and the API resources into the Windows installer.
Generated artifacts stay under root `dist/apps/zetro/desktop`.
Existing installed data and running services are not changed by packaging.
