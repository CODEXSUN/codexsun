# Zetro Desktop 0.1.21

## Scope and bindings

This release packages the Automation observation pages and public live progress.
Codex Connection `0.8.0` emits optional typed response/tool callbacks. Chat `0.14.0`
passes them to Supervisor `0.2.0`. Dependent manifest ranges match these public contracts.
System Tasks owns durable snapshots. Automation validates snapshots before display.
No table, migration, seed, token permission, or repository trust policy changed.

The [official App Server reference](https://learn.chatgpt.com/docs/app-server) defines
`item/started`, `item/completed`, and `item/agentMessage/delta`. Other notification
types, including reasoning, are not projected into the progress feed.

Snapshots coalesce every two seconds, retain the latest 40 tool actions, and bound
response excerpts to 8,000 characters. Common credential patterns are redacted.
The final result replaces partial evidence. Script stdout still appears at completion.
Slow or disconnected clients receive snapshots through existing task polling, not SSE.
