# Zetro 2.0 product rebuild

## Status

Planning. No product workflow is implemented.

## Current boundary

The active Zetro application is a presentation-only web shell. It has no
desktop, backend, provider, persistence, task execution, repository access, or
release automation.

## First design subject

Refine only the Chat stage:

1. Discuss an idea.
2. Plan the requested outcome.
3. Review the plan.
4. Attach and classify references.
5. Create one structured task draft after explicit confirmation.

Implementation starts only after this contract, its data ownership, failure
states, security boundary, and acceptance tests are approved.

## Excluded work

Project Tasks, System Tasks, implementation, verification, repair, acceptance,
delivery, release, and archive workflows remain outside the first rebuild stage.
