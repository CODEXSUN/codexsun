# Asset Policy

## Ownership

Store reusable visual, media, font, icon, and brand assets in a named package or approved asset location.

An application may reference a shared asset. It must not copy the asset into another application without a documented reason.

## Required metadata

Record source, license, owner, permitted use, attribution requirement, and optimization status for each external asset.

Do not add unlicensed assets, private customer material, or credentials to the repository.

## Delivery

Build assets into root `dist/` output only. Keep source assets outside application build folders.
