# Operations

Store runtime, monitoring, backup, and incident procedures here. Deployment
configuration belongs to the selected external runtime, not this repository.

Read the [versioning and release rules](versioning.md) before a version or release change.

Read [line endings](line-endings.md) before staging files or using `github:now`.

Read the [runtime layout](runtime-layout.md) before you add storage, container, or deployment files.

Read the [workspace runtime](workspace-runtime.md) before you add dependencies, build outputs, or TypeScript configuration.

Read [isolated application development](isolated-app-development.md) before you start parallel app work.

Read the [isolated app session skill](../skills/isolated-app-session/SKILL.md) before an agent starts app work in a worktree.

Read the [Redis runtime scaffold](redis-runtime.md) before adding a Redis service or delivery provider.

Read [backup and recovery](backup-and-recovery.md) before a migration, deployment, or rollback.

Read the [data lifecycle](data-lifecycle.md), [identity and security](identity-and-security.md), [observability](observability.md), and [deployment profiles](deployment-profiles.md) before implementation or deployment work.

Do not store credentials or other secrets in this folder.
