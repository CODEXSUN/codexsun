# UIUX Module Catalog

## Application ownership

UIUX owns the runnable design-system documentation experience. Its web workspace is documented in
[apps/uiux](../../apps/uiux/README.md). The application owns gallery pages, catalogs, previews,
examples, routes, navigation, and browser state. [`packages/ui`](../../packages/ui/README.md)
owns the reusable UI library and public contracts.
