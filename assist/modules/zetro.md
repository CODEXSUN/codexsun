# Zetro 2.0 Module Catalog

Zetro is a focused browser chat with a local API that connects to the installed
Codex CLI and stores history in SQLite. The v1 modules remain retired in the backup.

| Module            | Version | Runtime   | Composition | Documentation                                               |
| ----------------- | ------- | --------- | ----------- | ----------------------------------------------------------- |
| `zetro.chat.api`  | 1.1.0   | Zetro API | Active      | [Chat API](../../apps/zetro/api/src/modules/chat/README.md) |
| `zetro.shell.web` | 2.2.0   | Zetro web | Active      | [Shell](../../apps/zetro/web/src/modules/shell/README.md)   |

There is no desktop, queue, task, automation, repository, worktree, Git delivery,
or provider-settings module.
