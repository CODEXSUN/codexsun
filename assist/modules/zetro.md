# Zetro 2.0 Module Catalog

Zetro is a focused browser chat with a local development bridge to the installed
Codex CLI. The v1 modules remain retired in the external dated backup.

| Module            | Version | Runtime   | Composition | Documentation                                             |
| ----------------- | ------- | --------- | ----------- | --------------------------------------------------------- |
| `zetro.shell.web` | 2.0.0   | Zetro web | Active      | [Shell](../../apps/zetro/web/src/modules/shell/README.md) |

There is no separate Zetro API, desktop, database, queue, task, automation,
repository, worktree, Git delivery, or provider-settings module.
