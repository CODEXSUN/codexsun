# UI Module Catalog

## Application ownership

UI owns the runnable design-system documentation experience. Its web workspace is documented in
[apps/ui](../../apps/ui/README.md). The application owns the gallery pages, catalogs, previews,
examples, and browser wiring. [`packages/ui`](../../packages/ui/README.md) owns the reusable UI
library and public contracts.
