# Deployment Profile Template

## Identity

State client identifier, environment, owner, and target date.

## Composition

List selected applications, add-ons, module providers, and client targets.

## Infrastructure

List databases, queues, storage, containers, ports, domains, and external dependencies.

## Configuration

List required root `.env` and app `.app.env` variable names. Do not include values or secrets.

## Verification And Rollback

List local, Docker, and production checks. State backup, rollback, and incident contacts.
