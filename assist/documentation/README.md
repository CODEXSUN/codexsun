# Documentation

## Purpose

This guide defines the minimum documentation for CODEXSUN work.

Read the [changelog](CHAGELOG.md) for the repository progress record.

Read the [documentation standards](standards.md) before you add or update documentation.

## Required documentation

Each application and package must have a README that states:

- its purpose and owner;
- its public interfaces and dependencies;
- its local setup and verification commands;
- its configuration and required environment values.

## Writing rules

Use clear, direct language. Keep one name for one concept. Describe current behavior, not planned behavior.

Use relative links for documents inside this repository. Update links when files move.

## Decision records

Create a decision record for a change that affects repository boundaries, public contracts, shared data, security, or deployment.

Each record must state the context, decision, alternatives, consequences, owner, and review date.
