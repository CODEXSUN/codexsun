# Skills

Store focused task guidance that supports repeatable repository work here.

Read the [skill authoring guide](authoring.md) before you add a repository skill.

Each skill must state its purpose, scope, required inputs, and verification steps.

- [Progressive development](progressive-development.md) defines the repeatable delivery and handover workflow.
- [Module ownership](module-ownership.md) defines module boundaries and required owned artifacts.
- [Workspace runtime](workspace-runtime.md) defines root-only installs, output, configuration, and checks.
