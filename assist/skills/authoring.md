# Skill Authoring

## Purpose

A repository skill gives agents focused instructions for one repeatable task.

## Required content

- purpose and scope;
- applicable modules and paths;
- required inputs and safety limits;
- implementation sequence;
- verification checks;
- documentation and changelog updates;
- known exclusions.

## Rules

Keep a skill narrow and current. Link to architecture or module documentation instead of duplicating large policies.

Do not include secrets, provider credentials, or private reasoning. Review a skill when its owner module changes.
