# UIUX Gallery Delivery Plan

## Identity

Application: UIUX Gallery

Task prefix: `UX`

## Product Direction

UIUX Gallery documents and previews the published `@codexsun/ui` system. It
uses shared UI contracts and owns only gallery routes, catalogs, specimen data,
and browser state. It does not duplicate package components or product logic.

## Current Work

### Phase UX-1200: Shared UI Compatibility

- [x] UX-1201 Align Gallery routes, documentation, UI package exports, and
      validation with the MainWorkspace, Mdi, and Static Pages model.

Exit: the Gallery documents each supported route, validates the shared UI
system, and loads component specimens without exceeding the chunk budget.

### Phase UX-1210: Shared Editor
