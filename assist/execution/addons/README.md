# Add-On Execution Records

Create one folder for each add-on at `assist/execution/addons/<addon>/`.

Each add-on must copy `assist/templates/app-planning.md` as `planning.md` and `assist/templates/app-task.md` as `task.md` before code starts.

An add-on needs a unique uppercase prefix. Its planning and task records follow the same approval sequence as applications.
