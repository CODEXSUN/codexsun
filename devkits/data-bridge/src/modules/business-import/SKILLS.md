Keep Summary, Common, Masters, Billing, Invoices, and Warnings in separate tabs.
Mount only the active tab and paginate row details.
Distinguish imported, existing, warning, and skipped outcomes.
Show extracted source, prepared target, saved target, and foreign ID verification details.
Invoice drill-down must filter to that invoice and its saved child IDs.
Never present the whole table as one invoice's data.
Use fixed API clients and existing UI primitives.
Do not build SQL or expose credentials in the browser.
State table transaction boundaries without long helper sections.
