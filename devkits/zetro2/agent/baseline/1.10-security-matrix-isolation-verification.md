## 1. Security Matrix Invariants Tested

| Scenario | Tested Invariant | Result |
| --- | --- | --- |
| **Unauthenticated Request** | Requests lacking valid Bearer token return HTTP 401 Unauthorized immediately. | PASS |
| **Non-Member Access** | Authenticated actor attempting to read or write a workspace where they lack membership returns HTTP 403 Forbidden. | PASS |
| **Insufficient Capability** | `Viewer` attempting `workspace.write`, `change.approve`, or peripheral execution returns HTTP 403 Forbidden with missing capability. | PASS |
| **Client ID Substitution** | Client spoofed headers (`x-zetro2-actor-id`, `x-zetro2-role`) are stripped/ignored; actor ID is strictly bound to cryptographic JWT claims verified against server SQLite. | PASS |
| **TTL Session Expiration** | Advancing controlled test clock past TTL immediately revokes session access with HTTP 401. | PASS |
| **Dynamic Role Changes** | Modifying member role in database immediately applies to the next request on the same session/token (server-resolved membership) without requiring re-login. | PASS |
| **Cross-Workspace Reads** | Member of Workspace A attempting to read resources, list members, or view approvals in Workspace B is strictly denied with HTTP 403. | PASS |
