  2026-05-20, read-only**. Active development moved into
  `https://github.com/microsoft/vscode`.

  license MIT (`LICENSE.txt`), `main: ./dist/extension`.

## 3. Service contracts and branding

- `product.json` `defaultChatAgent` points at `GitHub.copilot` /
  `GitHub.copilot-chat` with GitHub URLs: entitlement
  `https://api.github.com/copilot_internal/user`, token
  `.../copilot_internal/v2/token`, MCP registry
  `https://api.github.com/copilot/mcp_registry`, plus aka.ms docs/terms/
  privacy/plan links.
- Auth path: `vscode.github-authentication` (bundled) with scopes
  `read:user`, `user:email`, `repo`, `workflow`.
- Upstream requires an **active GitHub Copilot subscription** (Free or paid);
  a copied extension supplies **no** credentials or entitlement by itself.
- Local repo holds **no** Copilot tokens or secrets (grep over
  `devkits/zetro2/{editor,api,web}` clean); only public entitlement URLs
  in `product.json`.

## 4. Decision

- **Do not copy or bundle Copilot Chat** into Zetro2 on this baseline:
  version-incompatible, archived upstream, subscription-gated, and
  trademark/brand encumbered (GitHub/Microsoft marks, aka.ms links).
- Proceed with the Zetro2 bridge plan (planning §7): native chat +
  inline-chat surfaces wired to Zetro2 model/backend adapters; revisit
  Copilot only as an accounted upstream-merge task after an editor rebase
  to `^1.115.0`+ with license, API-proposal, and entitlement review.
