Additional invariants proven in the same suite:

- Unauthenticated requests to `auth/me`, `workspaces`, members, resources, audit-logs, approvals, runs, and events all return HTTP 401.
- Forged `x-zetro2-actor-id` and `x-zetro2-role` headers cannot bypass Viewer write denial; the server resolves identity from the token only.
- Editor and preview gateways return 401 with no token, 401/403 with garbage or `undefined` bearer tokens, and 403 for non-members, with zero requests observed at the mock upstream for every denied case.
- A valid Developer member reaches both upstreams (control case), proving the gateway is live while denials are enforced before proxying.
