## 2. Integration and Boundary Specifications

### 2.1 LangGraph JavaScript (`@langchain/langgraph@0.2.20`)
- **Role:** LangGraph owns the outer engineering lifecycle state machine. It does not dictate individual prompt tokens or low-level file edits; rather, it governs:
  - Phase and milestone transitions (`planning` → `task_approval` → `agent_run` → `verification` → `human_review` → `completed`).
  - Human-in-the-loop interruption points (`interrupt()` before high-risk operations, approval gates, or diff commits).
  - Durable checkpointing via SQLite checkpointer (`storage/apps/private/zetro2/checkpoints.sqlite`).
- **Isolation:** Operates strictly within the Zetro2 API service boundary.

### 2.2 Model Context Protocol (`@modelcontextprotocol/sdk@1.0.4`)
- **Role:** Implements client and host connections for MCP servers.
- **Specification:** Conforms to protocol version `2024-11-05` / `2025-03-26` JSON-RPC over stdio and SSE/HTTP.
- **Security Boundaries:**
  - MCP servers execute inside dedicated container boundaries or restricted subprocesses.
  - Per-workspace MCP configuration (`mcp.manage` permission required).
  - Outgoing tool invocations pass through approval gates if marked dangerous or unconfirmed.

### 2.3 Playwright (`playwright@1.48.2`)
- **Role:**
  - Used by verification fixtures to validate Zetro2 web portal (`http://127.0.0.1:6310`) and Zbrowser preview (`http://127.0.0.1:6155`).
  - Exposes headless browser tool endpoints (`navigate`, `click`, `fill`, `screenshot`, `evaluate`) for agent verification loops.
- **Isolation:**
  - Headless browser runs inside the private Docker network or host fixture with isolated temporary user data directories.
  - Screenshots and artifacts are saved exclusively to root `dist/zetro2/artifacts/` or `storage/apps/private/zetro2/artifacts/`.

### 2.4 OpenCode Backend (`@opencode/sdk@0.1.28`)
- **Role:** Provides an out-of-the-box coding agent engine supporting direct model connections and tool execution.
- **Integration Boundary:**
  - Abstracted behind Zetro2's `AgentBackend` interface.
  - Translates Zetro2 workspace context and memory bank into OpenCode session parameters.
  - Intercepts file change requests to enforce Zetro2 write leases and human conflict protection.

### 2.5 OpenHands Software Agent (`ghcr.io/all-hands-ai/openhands:0.14.2`)
- **Role:** Advanced autonomous coding agent runtime.
- **Integration Boundary:**
  - Deployed as an optional companion container in Docker Compose.
  - Communicates with Zetro2 API via a typed TypeScript REST/WebSocket adapter (`OpenHandsBackend`).
  - No direct Python dependencies introduced into the Node.js/TypeScript host codebase.
