## Mechanism notes

- `product.enableTelemetry: false` gates `supportsTelemetry` in
  `telemetryUtils.ts` and disables first-launch telemetry opt-out messaging.
- `enabledTelemetryLevels` is read by `TelemetryService` / `mainThreadTelemetry`.
- Default `extensions.allowed` as a non-`'*'` object makes
  `AllowedExtensionsService.getAllowedExtensionsValue` return a map; gallery
  installs and enablement of `ExtensionType.User` not on the list are denied.
  System/bundled extensions are not checked. A global deny-list is intentional
  for private product posture; broader profiles remain a Phase 3 access concern.
- `defaultChatAgent` stays `GitHub.copilot` because `IProductConfiguration`
  requires it; Chat Layer (task 4 / Layer 3) replaces the agent backend.
