## 2. Invariants & Security Guardrails

1. **Private Upstream Isolation:**
   - Editor (ZVcode) and preview servers run on private loopback ports (6305, 6155). The gateway gates all access; no unauthenticated or cross-workspace traffic can reach private upstreams.
2. **Untrusted Client Identity Stripping:**
   - Any client-sent `x-zetro2-actor-id`, `x-zetro2-workspace-id`, `x-zetro2-role`, or `x-zetro2-readonly` headers are stripped prior to proxying.
   - Upstreams receive only server-validated identity and role headers.
3. **Readonly Role Mount Flags:**
   - For read-only roles (`Viewer` and `Reviewer`), the gateway sets `x-zetro2-readonly: true`, instructing upstream editor hosts to prevent terminal creation or file modifications.
4. **Browser & Iframe Query Param Authentication:**
   - Accepts authentication tokens via `?token=` query param in addition to `Authorization: Bearer` headers, enabling iframe and direct browser tab navigation.
5. **Upstream Failure Resiliency:**
   - If an internal upstream service is unreachable or terminates prematurely, the gateway responds with HTTP 502 Bad Gateway instead of leaking internal traces.
