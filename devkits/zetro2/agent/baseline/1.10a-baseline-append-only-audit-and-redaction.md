## 2. Invariants & Security Guardrails Enforced

1. **Strict Append-Only Immutability:**
   - Audit records cannot be modified or deleted via repository methods.
   - Every log entry retains its creation timestamp, UUID identifier, target resource, action type, and actor ID.
2. **Deterministic Credential Redaction:**
   - All structured `details` are scanned against registered `SecretsProvider` patterns before JSON serialization and database insertion.
   - Raw database queries verify that plaintext secret keys, bearer tokens, and JWT secrets are replaced with `[REDACTED]`.
3. **Restricted Audit Inspection:**
   - Audit logs are accessible only to workspace owners holding `workspace.admin`. Developers, Maintainers, and Viewers receive HTTP 403 Forbidden.
