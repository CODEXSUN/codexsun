## 2. Unresolved Compatibility Limits & Forward Dependencies

1. **Copilot Chat 0.44.0 Incompatibility:**
   - **Limit:** Upstream VS Code Copilot Chat 0.44.0 requires VS Code engine `^1.115.0`. ZVcode is based on OpenVSCode Server 1.110.0. The extension is closed-source/archived and subscription-gated.
   - **Resolution:** Confirmed not to bundle or adapt Copilot Chat. Zetro2 implements its own native chat provider, model routing, and agent backends in Phase 4 and Phase 6.
2. **Port 6300 Collision Precaution:**
   - **Limit:** Both `devkits/zetro2` and `devkits/orship` declare port 6300 for API in their respective `.app.env`.
   - **Resolution:** Running both simultaneously on the same host network interface is prevented by `tools/preflight.mjs`. Development work on Zetro2 runs independently.
3. **Container-Isolated Compilation Requirement:**
   - **Limit:** Host-side `npm install` inside `devkits/zetro2/zvcode/` would violate repository root layout rules (`tools/check-root-layout.mjs`) by creating nested `node_modules/`.
   - **Resolution:** Compilation and packaging of ZVcode is strictly isolated to Docker container builds (`devkits/zetro2/.container/Editor.Dockerfile`). Host workspace runs only TypeScript checks and API tests.
4. **Fixture vs. Live Execution Delineation:**
   - **Limit:** Phase 0 test verification relies on deterministic test fixtures (`clock`, `identity`, `backend`, `playwright`, `api`).
   - **Resolution:** Early passing checks do not represent live backend or browser execution. Phase 1 through Phase 5 incrementally replace fixture boundaries with live SQLite migrations, authenticated gateways, container networking, and live Playwright validation.
5. **Human Direct-Edit Precedence:**
   - **Limit:** Uncoordinated concurrent edits between human developers and autonomous agents risk data loss.
   - **Resolution:** Write leases and unsaved-buffer checks prevent silent overwrites; conflicts generate interactive diff proposals for human review.
