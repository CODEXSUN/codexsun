## 1. Assist Rule and Architectural Isolation Mandate

The Codexsun repository rules (`assist/governance/repository-architecture-rules.md` and `assist/governance/coding-agent-rules.md`) strictly mandate:
- **No Private Cross-App Imports:** Applications must not import private implementation files from another application (e.g. `import ... from '../../zcode/...'` or relative imports across `devkits/`).
- **Domain Independence:** Zetro2 is an independent product devkit that owns its full lifecycle, source code, container definitions, and extensions.
- **Shared Primitives via Central Packages:** Any functionality shared across apps must be accessed exclusively through public exports of `@codexsun/platform-core` or `@codexsun/framework`.
