## 1. Private Source and Non-Distribution Settings

To ensure no unintended exposure or leakage of proprietary code, custom layers, or internal configurations:

### 1.1 Package Manifest Boundaries
- `devkits/zetro2/zvcode/package.json` explicitly declares `"private": true`.
- `devkits/zetro2/api/package.json` declares `"private": true`.
- `devkits/zetro2/web/package.json` declares `"private": true`.
- Neither ZVcode nor Zetro2 packages are published to any public package registry (e.g. npm, Open VSX, or VS Code Marketplace).

### 1.2 Telemetry and External Endpoint Sanitization
- Upstream telemetry endpoints in `product.json` and client extensions are disabled or pointed to local/null destinations.
- Update check endpoints (`updateUrl`) are omitted, preventing background network polls to external distribution servers.
- Embedder identifier is set strictly to `"zvcode"` (`product.json`).
- Application names and protocol handlers are rebranded:
  - `applicationName`: `"zvcode"`
  - `serverApplicationName`: `"zvcode"`
  - `urlProtocol`: `"zvcode"`
  - `dataFolderName`: `".zvcode"`
  - `serverDataFolderName`: `".zvcode"`

### 1.3 Container Distribution Restrictions
- Docker container images built from `devkits/zetro2/.container/` are tagged for private, local development registries only (e.g. `codexsun/zetro2-editor:local`).
- Docker Compose files do not push to public Docker Hub, GitHub Container Registry, or other public registries without explicit administrator action.

## 2. Upstream License and Notice Preservation

The imported editor source (`devkits/zetro2/zvcode/`) is derived from OpenVSCode Server (Gitpod GmbH) and Visual Studio Code (Microsoft Corporation), licensed under the MIT License.

### 2.1 Preserved Legal Documents
1. **Primary MIT License:**
   - Path: `devkits/zetro2/zvcode/LICENSE.txt`
   - Preserves copyright notices for Microsoft Corporation and Gitpod GmbH.
   - Text is identical to `apps/temp/openvscode-server/LICENSE.txt`.
2. **Third Party Notices:**
   - Path: `devkits/zetro2/zvcode/ThirdPartyNotices.txt`
   - Contains notices and attributions for all bundled dependencies and libraries.
   - Text is identical to `apps/temp/openvscode-server/ThirdPartyNotices.txt`.

### 2.2 Distribution and Packaging Invariants
- Whenever ZVcode is packaged (e.g. via `build/gulpfile.reh.ts` into a container image layer or tarball), `LICENSE.txt` and `ThirdPartyNotices.txt` must remain in the root directory of the binary distribution.
- Automated verification in CI checks:
  ```powershell
  node devkits/zetro2/editor/verify-zvcode.mjs
  ```
  which asserts:
  ```javascript
  for (const path of ["LICENSE.txt", "ThirdPartyNotices.txt"]) {
    assert.equal(await read(editor, path), await read(source, path), path);
  }
  ```
