## 1. Fixtures Architecture & Components

Zetro2 establishes deterministic test fixtures in `devkits/zetro2/api/test/fixtures/` to enable rigorous test-driven development across early phases before live container and remote services are integrated:

| Fixture Module | Exported Factories | Capabilities & Responsibilities | Boundary & Invariant |
| --- | --- | --- | --- |
| `clock.mjs` | `createTestClock(initialDate)` | Deterministic time progression (`now()`, `advance()`, `advanceMinutes()`, `advanceHours()`, `set()`). | Guarantees repeatable verification of write leases, 5-minute approval tokens, and 24-hour task validity windows without wall-clock sleep. |
| `identity.mjs` | `createTestIdentityFixture()`, `createTestJwt()`, `ROLE_PRESETS`, `TEST_USERS` | Canonical definitions of 5 roles (`Owner`, `Maintainer`, `Developer`, `Reviewer`, `Viewer`), 12 fine-grained permissions, and test JWT generator. | Decoupled from private external apps; adheres to `@codexsun/platform-core` identity schema conventions. |
| `backend.mjs` | `createTestBackendFixture()` | Deterministic agent backend lifecycle simulation (`startRun()`, `proposeToolCall()`, `proposeDiff()`, `cancelRun()`, `completeRun()`, `onEvent()`). | Separates Task entities from Run attempts; emits discrete lifecycle events for workflow engines. |
| `playwright.mjs` | `createPlaywrightArtifactManager(repoRoot)`, `resolveRepoRoot()` | Headless browser context parameters and artifact path resolver (`getArtifactPath(testName, fileName)`). | **Strict Root Dist Boundary:** Artifacts are saved exclusively under `dist/zetro2/artifacts/`. Throws security violations on path escape attempts. |
| `api.mjs` | `createTestApiFixture(appFactory)` | Ephemeral in-process HTTP test harness running on port 0 (`127.0.0.1`), with helper methods (`get`, `post`, `put`, `delete`) and automatic cleanup. | Isolates test servers from production port 6300, avoiding collisions with host services. |
