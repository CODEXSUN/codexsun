## 2. Scoping Engine Invariants

1. **Path-level Scoping:**
   - Supports glob matching via `minimatch`.
   - `forbiddenPaths` takes precedence over `paths`: if a file matches a forbidden pattern, the grant is rejected.
2. **Tool-level Scoping:**
   - Allows wildcard patterns (e.g. `mcp:github/*`, `mcp:sqlite/*`) or exact tool identifiers.
3. **Command-level Scoping:**
   - Supports prefix matching (e.g. `npm test`, `git status`) to restrict terminal processes.
4. **Time Expiration:**
   - Grants may specify `expiresAt` (epoch seconds); expired grants are ignored by `CapabilityEvaluator`.
5. **Computer Use Disabled Invariant:**
   - `computer.use` is absent from all default preset configurations (`ROLE_DEFAULT_GRANTS`) and requires an explicit, audited administrative grant.
