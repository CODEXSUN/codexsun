## 2. Invariants & Security Guardrails Enforced

1. **Coordinated Session Revocation:**
   - Logging out or revoking a session atomically invalidates the JWT session in `SessionProvider`, purges all associated SSE subscriptions in `EventSubscriptionHub`, and triggers cancellation hooks for all active agent runs tied to that session in `RunCancellationCoordinator`.
2. **Membership Removal Propagation:**
   - Removing an actor from a workspace (`DELETE /api/v1/zetro2/workspaces/:ws/members/:userId`) immediately aborts and cancels all active agent runs associated with that actor within the workspace.
3. **Deterministic Run Cancellation Hooks:**
   - Every active agent run registers a cancellation hook callback `({ reason, cancelledBy, timestamp }) => Promise<void> | void`. When triggered, the hook notifies the runner (tested with backend simulator fixture) to abort execution.
4. **Audit Log Generation:**
   - Cancellations append an immutable audit log entry with action `run.cancelled`, recording the cancelling actor, the target run ID, and the cancellation reason.
5. **Idempotency & Replay Safety:**
   - Once cancelled or unregistered, subsequent cancellation requests return `{ cancelled: false }` safely without duplicate hook invocations.
