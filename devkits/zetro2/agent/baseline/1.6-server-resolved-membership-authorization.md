## 2. Invariants & Security Principles Enforced

1. **Zero Client-Side Trust:**
   - Client-supplied roles or workspace assertions are ignored. The server resolves membership directly from `zetro_workspace_memberships` using the authenticated actor ID.
2. **Cross-Workspace Isolation:**
   - Membership in Workspace A confers 0 permission to Workspace B. Non-members attempting access receive 403 Forbidden.
3. **Capability Gating on Resources:**
   - Viewers possessing `workspace.read` cannot write resources (`workspace.write` required) or manage members (`membership.manage` required).
4. **Authorized Event Subscriptions:**
   - Real-time event streams (`/api/v1/zetro2/workspaces/:workspaceId/events`) require valid token and server-resolved `workspace.read` membership. Non-members are rejected with 403 Forbidden.
5. **Session Revocation Subscription Purge:**
   - When a session is logged out or revoked, all associated event subscriptions are immediately closed.
