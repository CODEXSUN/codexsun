# ZVcode

ZVcode is the source-owned editor for Zetro2, derived from OpenVSCode Server.
Product configuration builds the server command as `zvcode` and uses `.zvcode` for data.

See [source integration](../editor/README.md) for changes, build boundaries, and verification.
See [upstream documentation](../editor/UPSTREAM-README.md) for original source context.
Inherited upstream commands are reference material, not verified Zetro2 deployment commands.

Status: source copied and product identity configured. Docker build, browser verification,
Zetro2 authentication, agent chat, and Zbrowser integration remain pending.
